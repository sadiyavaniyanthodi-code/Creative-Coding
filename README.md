# Creative-Coding
This is the repository for three experiments in creative coding created with the p5.js library. Different techniques such as real-time systems, procedural generation, animation, interaction and gameplay are explored in each experiment.

Experiments

Experiment 1.Real Time Clock

Alternate real-time clock visualisation in animated neon, particles and interactive theme switch.

Techniques:
-Real-time data
-Animation
-Rotation and transformation
-User interaction
-Experiment 2.Rainy Garden

A procedural landscape scene with animated rain, mountains, trees, flowers and lighting effects.

Techniques:
-Procedural generation
-Particle systems
-Environmental animation
-Layered composition
-Experiment 3.One Key Battle

A competitive game for two players, featuring particle effects, sound integration and visual feedback.

Techniques:
-Interaction design
-Game mechanics
-Sound integration
-Particle systems
